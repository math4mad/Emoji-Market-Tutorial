# Emoji Market Tutorial 📖

> 从对话到仪表盘：一个关于思想如何逐步演化为交互式系统的教程。

本教程记录了一次人机对话如何从一个简单的"运煤船—电厂"问题，逐步生长为一个复杂的 Emoji 市场经济模拟器，并最终沉淀为一座可交互的 **系统智能仪表盘**。

## 在线阅读

- GitHub Pages: <https://math4mad.github.io/Emoji-Market-Tutorial>
- 本地预览：安装 [Quarto](https://quarto.org) 后运行 `quarto preview`

## 章节概览

| 章节 | 主题 | 关键产物 |
|---|---|---|
| 1 | 缘起 | 🚢(x)=🏭(y) 的 emoji 等式 |
| 2 | 汇率矩阵 | 6×6 商品兑换矩阵 |
| 3 | 金融危机 | 危机概率、市场恢复 |
| 4 | 货币进化 | 从物物交换到 💎、⚡ 货币 |
| 5 | 国际贸易 | 跨王国汇率定价 |
| 6 | 能量块 | 算力能源数字货币 |
| 7 | AI 代理人 | 自动套利机器人 |
| 8 | 元宇宙出口 | 训练场隐喻 |
| 9 | 从市场到智能 | 交换链 ↔ 神经网络 |
| 10 | 系统智能仪表盘 | 可交互 Streamlit 应用 |

## 本地构建

```bash
# 安装 Quarto (macOS)
brew install quarto

# 预览
quarto preview

# 构建静态网站
quarto render
```
